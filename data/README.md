# Data

Raw data is not committed to Git. Runs are stored in `server/runs.db` and shared through the team drive.

Recording checklist, aim for 100 or more runs, each with a hand counted label.

| Variable | Values to cover |
| --- | --- |
| Lighting | bright, dim |
| Distance | 1.5 m, 2 m, 3 m |
| Clothing | dark, light, loose |
| Speed | slow, normal, fast |
| People | all four members, plus friends if possible |
